# Horizon

Esetleg majd a jövőben folytatom ha megjön hozzá a kedvem.

Az eredeti ötletet a "Teams" és a "Kreta" inspirálta. Egy olyan oldalt akartunk létrehozni ahol az iskolák jelentkezni tudnak a szolgáltatásunkra ami egy olyan felület lett volna ami megsegíti az online tanítást és felgyorsít pár adminisztrációs feladatot. Miközben szórakoztatóbbá és vonzóbbá tenné a tanulást és azt, hogy több energiát tegyünk a fejlődésünkbe.
